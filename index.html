How to read this register

Every figure comes from the JSON endpoints behind rera.rajasthan.gov.in: the project master list, each project's Form-A and Form-B payload, the unit and plot inventory, the cost estimate, the document register and the statewide complaint register. Nothing is read out of PDFs — approval letters, sanctioned plans and drawings are excluded.

Areas are square metres, the portal's native unit; switch to square feet in the header. The portal publishes one area figure per project, labelled “Total built up area / saleable area”: building projects file built-up (FSI), plotted layouts file saleable, and only 40 of 2,419 projects file both. This register shows that one declared figure, and keeps the two underlying columns apart in the project record and the data-quality tab. A blank area means the promoter filed neither — a gap on the portal, not a zero-area project.
