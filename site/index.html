How to read this data

Everything here is fetched from the JSON endpoints that back rera.rajasthan.gov.in — the project master list, each project's Form-A/Form-B payload, the unit/plot inventory, the cost estimate, the document register and the statewide complaint register. Nothing is read out of the PDFs (approval letters, sanctioned plans, drawings); only table data is used.

Areas are square metres, the portal's native unit (switch to sq ft in the header). A blank area means the promoter filed a zero or left the field empty — that is a data gap on the portal, not a zero-area project. “Built-up (FSI)” and “saleable” are separate Form-B heads and are frequently different (or one of them zero).
